Performance pass 21 August 2026 (reported as "lagger ved brukerhandlinger" and slow search). Measured before changing anything: artwork decode and downscale ran on the main actor at ~9 ms per cover, ~190 ms for a screenful of twenty; `transformFeeds` cost 80 ms for 400 feeds on the main actor, of which 75 ms was `htmlToText`; the per-row SwiftData progress fetch cost 0.06 ms and was not a factor. Fixed: artwork now decodes through ImageIO straight to the size needed, off the main actor (~9 ms to ~8 ms per cover, and off the frame), the memory cache reports a cost, a cached image no longer flashes the spinner on re-appearance, and every list-sized response transform runs off the main actor. Also closed LYT-07, LYT-14, LYT-15, LYT-37, LYT-38, LYT-50, LYT-51, LYT-54, LYT-55 from this tracker.

Player scrubber 18 August 2026: dragging the progress slider froze the position display while audio kept playing. Root cause was the scroll view added to the player that day; SwiftUI's end-of-drag callback is not delivered when another gesture recogniser takes the touch. The scroll view is now used only at accessibility sizes, and PlayerControls no longer depends on that callback — the drag is committed by a watchdog. Instrumented logging confirmed the callback can be absent entirely.

Documentation pass 18 August 2026: README, Brukerveiledning, Personvern, SECURITY, CLAUDE.md and the App Store checklist brought up to the current state; closed LYT-63, LYT-64, LYT-68.

The app also could not receive files from other apps at all; it now declares `org.opml.opml` and routes `onOpenURL` into the existing import. Six tests added, 256 total.
